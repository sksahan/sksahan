## 🚀 Projects & Research

### [Weeding Robot with CNC Arm](https://github.com/sksahan)
Precision weeding system with x-y-z control using NEMA17 + A4988, controlled by Arduino and camera vision.

### [Warehouse Line Following Bot](https://github.com/sksahan)
Bluetooth-connected robot with IR sensors and location control via a Java app.

### [Tea Leaf Withering Monitor](https://github.com/sksahan)
Python + MySQL system for real-time RGB/HSV-based leaf color tracking and classification.

### [Accommodation Finder Web App](https://github.com/sksahan)
A user-friendly PHP + MySQL application for finding suitable rental locations for students.
